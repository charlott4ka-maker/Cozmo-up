# База знаний Козмо

Положите сюда файлы `.txt` или `.md` — и Козмо начнёт это знать.

Как это работает: при запуске файлы разбиваются на абзацы (разделитель —
пустая строка). Когда вы о чём-то спрашиваете, подходящие абзацы
подкладываются в вопрос к ИИ. Поэтому:

* **разделяйте мысли пустой строкой** — один абзац, одна тема;
* **пишите своими словами** то, что реально хотите, чтобы он знал;
* **не бойтесь объёма** — ищутся только подходящие куски, а не всё сразу.

Поиск — по совпадению слов с обрезкой окончаний, без нейросетей. Работает
офлайн и всегда понятно, почему нашлось именно это.

Файл `pro_menya.md` — пример, замените его своим.
